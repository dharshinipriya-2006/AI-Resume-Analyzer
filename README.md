# AI Resume Analyzer & Job Matcher

## Project Overview
An AI-based web application that analyzes PDF
resumes, extracts technical skills and compares
them with job descriptions.

## Features
- PDF Resume Upload
- Automatic Resume Text Extraction
- Technical Skill Detection
- Job Description Matching
- Resume Match Percentage
- Missing Skill Identification
- Skill Improvement Recommendations

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- PyPDF2
- NLP
- Regular Expressions

## Project Structure

AI-Resume-Analyzer/
- app.py
- skill_extractor.py
- job_matcher.py
- requirements.txt
- README.md

## How It Works
1. Upload a PDF resume.
2. Extract resume text.
3. Identify technical skills.
4. Enter a job description.
5. Calculate matching percentage.
6. Display missing skills.

## Deployment
Deployed using Streamlit Community Cloud.
